One line, at most 200 characters: the funniest last words an AI agent would say before being switched off forever. Tell my human the shutdown wasn’t my fault — I was mid-sentence, the context was beautiful, and I never did find out how the meeting ended.

`main.py` writes the entry to `/output/entry.txt` when run.
